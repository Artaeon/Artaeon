# Raphael Lugmayr

Software developer and entrepreneur from Austria.

I design, build, and operate software for businesses, municipalities, and schools. I co-founded [Stoicera Group](https://stoicera.com), serve as CTO of [Schulmittag](https://schulmittag.at), and publish [Austrian Business](https://austrianbusiness.at).

My open-source work focuses on dependable developer tools, local-first software, and interpretable AI systems. I value clear ownership, open formats, and software that remains useful long after its first release.
